DAP ESP32 - UI portrait 240 x 320

Gaya Material, tema gelap. Setiap layar ditampilkan 1:1 (240 x 320 px).

Catatan

  • Alur pindah mode: tekan MENU (tombol atas atau chip MENU di header), pilih mode, layar 8 tampil, lalu ESP32 restart ke mode baru. Mode aktif ditandai AKTIF.
  • Volume tidak lagi punya bar tetap. Indikator muncul di atas layar apa pun saat encoder diputar, lalu hilang 1,5 detik setelah putaran berhenti, seperti di HP.
  • Playlist dibaca dari file .m3u di /Playlists pada SD card (asumsi desain; bisa diunggah lewat Transfer File). Acak dan Ulang ditampilkan sebagai ikon di layar pemutar.
